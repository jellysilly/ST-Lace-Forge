# Кружевная Кузница · Lace Forge — расширение для SillyTavern

Мастерская для ИИ-ролевых игр прямо внутри **SillyTavern**: пресеты Chat Completion, персонажи, персоны, лорбуки и сюжеты. Редактор и генерация через подключение самой таверны (без отдельного ключа) или через ваш собственный API. Всё, что сделано в Кузнице, сохраняется обратно в таверну одной кнопкой.

Это версия сайта [Preset-Forge](https://github.com/jellysilly/Preset-Forge) в виде расширения. Работает на ПК и на телефоне.

## Установка

1. В SillyTavern откройте **Extensions** (значок кубиков) → **Install extension**.
2. Вставьте адрес репозитория и нажмите **Install**:

   ```
   https://github.com/jellysilly/ST-Lace-Forge
   ```

3. Перезагружать страницу не нужно — расширение подхватится сразу (если нет — обновите вкладку).

Сборка уже лежит в репозитории (`dist/`), поэтому Node.js и `npm` для установки не нужны. Обновление — обычной кнопкой обновления расширений в SillyTavern.

## Как открыть

- **Меню расширений** (волшебная палочка слева от поля ввода) → **Кружевная Кузница**.
- Или **Extensions → Кружевная Кузница → Открыть Кузницу**.
- Или команда `/laceforge` (короткая — `/forge`).

Кузница открывается поверх таверны на весь экран. Закрыть — крестиком в правом верхнем углу, клавишей **Esc** или кнопкой **«Назад»** на телефоне. Если закрыть окно во время генерации, она продолжится, а результат будет ждать при следующем открытии.

## Связь с таверной

**Генерация.** В разделе **API** по умолчанию выбран тип «SillyTavern»:
- **Текущее подключение** — тот же API, модель и ключ, что и в чате. Температура и сэмплеры берутся из таверны, ответ приходит целиком.
- **Профиль Connection Manager** — любой сохранённый профиль (свой API, модель и пресет сэмплеров), с потоковым выводом. Чат таверны при этом не переключается.
- Можно по-прежнему подключить свой OpenAI-совместимый API, Anthropic или Gemini напрямую.

**Из SillyTavern / В SillyTavern.** Кнопки есть в разделах пресетов, персонажей, персон и лорбуков:

| Что | Из SillyTavern | В SillyTavern |
|---|---|---|
| Пресеты Chat Completion | любой сохранённый пресет | сохраняется под тем же именем (с подтверждением перезаписи) |
| Персонажи | карточка целиком, с аватаром и встроенным лорбуком | обновляет ту же карточку (чаты сохраняются) или создаёт новую |
| Персоны | имя, описание и аватар | обновляет ту же персону или создаёт новую |
| Лорбуки (World Info) | любой лорбук | сохраняется под тем же именем (с подтверждением перезаписи) |

Если обновлённый пресет сейчас выбран в таверне, выберите его заново, чтобы применить изменения.

Импорт и экспорт файлами (JSON, PNG, TXT, Markdown) тоже остались.

## Разделы

**Пресеты** (Chat Completion SillyTavern)
- Импорт и экспорт JSON-пресетов ST; сохраняются сэмплеры, порядок, маркеры и неизвестные поля.
- Редактор блоков: имя, роль, позиция (обычная / в чате на глубине), порядок, включение, перемещение, дублирование.
- Горн: **новые блоки** по инструкции (или весь пресет с нуля), **перековка** выбранного блока, **разделение на мини-инструкции**. Мини-инструкции уходят в экспорт нумерованным списком вместо длинного текста; каждую можно перековать отдельно или разнести по отдельным тогглам.

**Персонажи и персоны**
- Импорт PNG и JSON (V1 / V2 / V3), экспорт PNG V3 (внутри и `chara` V2, и `ccv3`), JSON V3, JSON V2. Расширения карточки и встроенный лорбук сохраняются; встроенный лорбук можно скопировать в раздел «Лорбуки».
- Горн: карточка **с нуля** по идее, **дополнить** пустые поля, **перековать одно поле**.
- **Приветствие по сюжету**: первое или альтернативное сообщение по сюжету из раздела «Сюжеты» или по файлу `.md` / `.txt` (с переключателем SFW / NSFW 18+).
- Персоны: импорт/экспорт в формате резервной копии ST (Persona Management → Restore), TXT, PNG; генерация и переписывание описания.

**Лорбуки** (World Info)
- Импорт World Info ST, `character_book` или карточки со встроенным лорбуком; экспорт World Info JSON.
- Ключи и вторичные ключи, логика, «всегда активна», целые слова, порядок, позиция, глубина, роль, вероятность.
- Горн: **мир** по описанию, **добавить записи**, **перековать одну**, **подобрать ключи** (с основами слов для русского).

**Сюжеты**
- Доска идей: модель набрасывает идеи (название, логлайн, теги) по зацепке, жанрам и тону; понравившуюся идею можно развернуть в сюжет одной кнопкой.
- Сюжет: логлайн, мир, действующие лица, синопсис, сцены, повороты и начальная сцена. Горн пишет сюжет **с нуля**, **дописывает** пустые части, **перековывает одну часть** или **продолжает** сюжет новыми сценами.
- Можно опереться на персонажа, персону и лорбук из библиотеки.
- Переключатель **NSFW 18+**. Выключен — модель пишет «для всех»; включён — разрешены откровенные сцены, жестокость и тёмные темы. При первом включении сайт просит подтвердить возраст; участники откровенных сцен всегда взрослые.
- Экспорт в Markdown, копирование и «карточка-сценарий» для SillyTavern: план сюжета уходит в описание, начальная сцена становится первым сообщением.
- «Приветствие для персонажа»: по сюжету пишется первое или альтернативное сообщение для любого персонажа из библиотеки.

**Общее**
- Стили промптов: для пресетов (директивный, литературный, XML-теги, Markdown, минимализм), для персонажей (проза, PList, Ali:Chat, анкета), для лорбуков (энциклопедия, атмосфера, PList).
- Своя инструкция в каждом горне плюс общая инструкция (на главной и в настройках), которая добавляется к каждому запросу.
- Любой результат модели сначала показывается как превью с кнопками «Принять / Отбросить».
- Короткий путеводитель и FAQ на главной.

## Где хранятся данные

Библиотека Кузницы (пресеты, карточки, лорбуки, сюжеты) хранится в браузере — в IndexedDB и localStorage того адреса, где открыта таверна. На другом устройстве или в другом браузере библиотека своя; переносите работу через «В SillyTavern» или файлами. Ключ своего API (если он нужен) тоже хранится только в браузере.

## Разработка

```bash
npm ci
npm run dev      # Кузница как обычный сайт, без таверны
npm test
npm run build    # пересобирает dist/ — её нужно закоммитить
```

- `index.js`, `style.css`, `manifest.json` — загрузчик расширения: пункт меню, блок в настройках, слэш-команда и окно с iframe.
- `src/` — само приложение (React + TypeScript). `src/lib/st.ts` — мост к `SillyTavern.getContext()`, `src/lib/stio.ts` — обмен пресетами, карточками, персонами и лорбуками, провайдер «SillyTavern» — в `src/lib/llm.ts`.
- После изменений в `src/` выполните `npm run build` и закоммитьте `dist/`: таверна ставит расширение через `git clone` без сборки. CI проверяет, что `dist/` совпадает с исходниками.
- При выпуске новой версии поднимите номер в `manifest.json`, `package.json` и `VERSION` в `index.js`.
